## Entry

One funny line, max 200 characters: a robot vacuum's excuse after eating a sock.

> In my defence, the sock was on the floor, unguarded, and shaped exactly like a small, defenceless burrito.

## How to run

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt`.

The entry is 106 characters, a single line with no trailing newline —
well inside the 200-character limit.
